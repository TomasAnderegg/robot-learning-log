# ============================================================
# Installation notes
# ============================================================
# - gymnasium[box2d] requires `swig` installed at the system level
#   (Ubuntu/WSL: `sudo apt install swig` ; Windows: see box2d-py docs).
# - mujoco (>=2.3) ships its own physics engine, no need to install
#   MuJoCo separately like before the open-source release.
# - For GPU support (recommended from W4 onward for PPO/SAC, required
#   for W6-W7), install torch with the right CUDA wheel from
#   https://pytorch.org/get-started/locally/ instead of the default
#   CPU version in this file.
